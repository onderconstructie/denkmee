# Werkafspraken

## Persoonlijke notities horen niet in git

Persoonlijke notitieverzamelingen (zoals een Obsidian-vault) mogen **nooit** in
een git-repo terechtkomen — niet publiek, niet privé, niet als fragment in een
commit, issue, PR of comment.

Concreet:
- Geen sync-oplossing voorstellen of opzetten die zulke notities naar GitHub duwt.
- Geen inhoud eruit citeren of overnemen in bestanden van deze repo.
- Toegang ertoe regelen kan alleen lokaal op het toestel zelf, buiten git om.
